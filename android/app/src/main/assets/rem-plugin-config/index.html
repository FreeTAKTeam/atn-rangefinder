How it works

Open the plugin, tap Scan for Binox, pick your Binox and answer Is this phone with the binocular?

Each measurement then becomes a REM marker, and REM markers within the Binox's range appear on it automatically, in NATO colours.

Allow ATN Rangefinder's map permissions above, including "Read all map markers near this device".
